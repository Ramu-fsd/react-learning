## Capstone
Build a payment operations portal with:
- Payment search and detail routes
- Beneficiary onboarding form
- Typed API service layer
- Shared filters and selected-payment state
- Pending-payment metrics
- Error/loading/empty states
- Role-aware UI as a presentation feature, with authorization enforced by backend APIs
