# React Interview Preparation

## Core questions
1. What problem do React hooks solve?
2. What causes a component to re-render?
3. What is the difference between `useMemo` and `useCallback`?
4. Why should effects clean up subscriptions and timers?
5. How do you prevent stale requests from updating the UI?
6. What is the difference between client state and server state?
7. When would you choose Redux Toolkit over Context?
8. How does React Router represent nested routes?
9. Why is frontend validation insufficient for security?
10. How do you investigate a slow React screen?

## Senior-level discussion prompts
- Design a transaction search UI for millions of records. Discuss server-side filtering, pagination, cancellation, caching and observability.
- Design a beneficiary onboarding workflow with conditional fields and server validation.
- Explain how frontend role-based rendering differs from backend authorization.
- Describe a safe UX for payment approval and maker-checker workflows.
- Explain how you would measure and reduce unnecessary renders in a complex dashboard.
