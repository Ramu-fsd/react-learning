
# 04 - React Learning

Practical React + TypeScript learning modules focused on enterprise and fintech workflows.

## Modules

| Module | What you will learn | Domain example |
|---|---|---|
| `api-integration` | Typed API clients, loading/error states, cancellation, retries | Payment transaction search |
| `forms-validation` | Controlled forms, React Hook Form, Zod validation | Beneficiary onboarding |
| `hooks-examples` | Built-in and custom hooks | Account and payment operations |
| `performance-optimization` | Memoization, lazy loading, profiling, large lists | Transaction operations dashboard |
| `routing` | Nested routes, route parameters, navigation, protected UI | Banking operations portal |
| `state-management` | Redux Toolkit, slices, selectors, async thunks | Shared payment operations state |

## Prerequisites

- Node.js 20 or later
- npm
- Basic JavaScript, TypeScript, HTML and CSS knowledge
- Familiarity with React components, props and state

## Suggested learning order

1. `hooks-examples`
2. `api-integration`
3. `forms-validation`
4. `routing`
5. `state-management`
6. `performance-optimization`

Each module has its own README and can be studied independently. The examples use simulated data and APIs; they are educational demonstrations, not production banking integrations.

## Run the examples

From this directory:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

```bash
npm run build
npm run lint
```

## Technology stack

- React 19
- TypeScript
- Vite
- React Router
- Redux Toolkit
- React Hook Form
- Zod
