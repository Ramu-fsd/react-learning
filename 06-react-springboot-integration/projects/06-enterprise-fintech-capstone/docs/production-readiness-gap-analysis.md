# Production Readiness Gap Analysis

The capstone is a learning starter. Before any production use, design and implement:

- OAuth2/OIDC resource-server authentication and fine-grained authorization
- Idempotency keys with durable request outcomes
- Transactional outbox to atomically persist state and publish events
- Payment state machine with valid transition rules
- Maker-checker controls and segregation of duties
- Double-entry ledger and immutable journal
- Sanctions, fraud, limits and compliance checks
- Reconciliation and exception handling
- Audit trail and data retention policies
- Secrets management, TLS/mTLS and network segmentation
- Resilience, retries, DLQ, backpressure and operational runbooks
- Database migrations, backups, HA/DR and disaster recovery testing
- Metrics, logs, traces, alerting and SLOs
- Threat modeling, penetration testing and secure SDLC
