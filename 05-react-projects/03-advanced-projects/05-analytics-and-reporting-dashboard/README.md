# Analytics and Reporting Dashboard

An executive reporting workspace for synthetic payment volume, success rate, channel mix and monthly trends.

## Features
- KPI cards for volume, value and success rate
- Monthly payment trend visualization using CSS bars
- Channel mix and status distribution
- Date-range preset and channel filter
- Export visible data to CSV

## Run
```bash
npm install
npm run dev
npm run build
npm run lint
```

## Design notes
The chart is deliberately built with CSS and semantic markup to keep dependencies minimal. For production, choose a charting library based on accessibility, data volume and interaction requirements.
