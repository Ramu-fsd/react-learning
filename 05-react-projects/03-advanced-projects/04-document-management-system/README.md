# Document Management System

A KYC and compliance document workspace with metadata, status review and local file selection.

## Features
- Register a document with customer, document type and reference
- Select a local file and display its filename and size
- Filter by verification status and search metadata
- Mark a document as verified or rejected in demo state
- Track document review status

## Run
```bash
npm install
npm run dev
npm run build
npm run lint
```

## Security
The file input is a UI demonstration only. It does not upload or persist file contents. Production upload needs server-side type/size validation, malware scanning, encryption, access controls, retention policies and secure object storage.
