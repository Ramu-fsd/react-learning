# KYC Onboarding Portal

A multi-step customer onboarding experience with applicant details, document checklist and review status.

## Features
- Three-step onboarding flow
- Applicant profile and contact validation
- Customer type and country selection
- Document checklist with completion progress
- Review summary and submission confirmation
- Resume navigation between steps during the session

## Run
```bash
npm install
npm run dev
npm run build
npm run lint
```

## Security and compliance
This is a UI workflow only. It does not verify identity or collect/upload real documents. Production KYC requires secure identity verification, consent, data minimization, encrypted document storage, sanctions/PEP screening and auditable decisions.
