# Loan Origination Platform

A lending workflow UI for capturing a loan application, estimating an illustrative installment and tracking application stages.

## Features
- Applicant and loan details form
- Positive amount, term and income validation
- Illustrative EMI calculator
- Application list and lifecycle statuses
- Advance application stage in demo state
- Search applications by applicant/reference

## Run
```bash
npm install
npm run dev
npm run build
npm run lint
```

## Important
The installment estimate is illustrative and not a lending offer. This app does not perform credit scoring, underwriting or approval. Production lending requires regulated policy controls, affordability checks, credit bureau integration, explainable decisions and audit trails.
