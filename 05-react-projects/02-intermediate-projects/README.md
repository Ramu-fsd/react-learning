# Intermediate React Projects - Implementations

Six standalone React 19 + TypeScript + Vite applications with synthetic fintech and enterprise data.

## Applications

1. `01-transaction-management-dashboard` - transaction search, status filters, pagination, detail view and CSV export.
2. `02-customer-management-portal` - customer create, edit, activate/deactivate and search.
3. `03-expense-management-app` - expense submission, validation, filtering and approval/rejection workflow.
4. `04-banking-account-dashboard` - account overview, balance masking and searchable transaction history.
5. `05-payment-tracker-app` - payment lifecycle tracking, event timeline and demo retry action.
6. `06-service-request-management` - request creation, priority, assignment, filtering and status workflow.

## Run any application

Open a terminal in the selected project directory and run:

```bash
npm install
npm run dev
```

Build and lint:

```bash
npm run build
npm run lint
```

Each application is independent and has its own `package.json` and README.

## Important
These are frontend portfolio implementations using mock data and local React state. They do not connect to a backend or perform real financial operations. For production, implement authentication, authorization, validation, audit, idempotency and persistence in trusted backend services.
