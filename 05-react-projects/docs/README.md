## Suggested learning order

1. React fundamentals and TypeScript
2. React Hooks and component composition
3. Advanced React patterns and performance
4. Beginner, intermediate and advanced projects
5. Fintech enterprise projects
6. React + Spring Boot integration
7. React system design and architecture

## How to use this folder

- Copy `project-readme-template.md` into a project and replace all placeholders.
- Follow the roadmap in sequence, but build small applications continuously.
- Document architectural decisions and trade-offs instead of only listing features.
- Clearly distinguish simulated frontend behavior from real backend capabilities.

## Important

Portfolio applications may use mock data or local state. Do not describe simulated authentication, payments, fraud detection, KYC, or authorization as production functionality unless a real backend and the required controls are implemented and tested.
