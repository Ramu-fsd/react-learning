# React Projects Roadmap

## Phase 1 - Beginner
Complete the six existing small apps. Learn component composition, state, events, controlled inputs and list rendering.

## Phase 2 - Intermediate
Build a transaction dashboard first. Reuse its API, filtering, pagination and detail-view patterns in customer, expense and payment-tracker applications.

## Phase 3 - Advanced
Build modular enterprise experiences. Add test coverage, route-level splitting, accessibility, profiling and documented architecture decisions.

## Phase 4 - Fintech enterprise
Build the domain capstones. Prioritize realistic workflows and non-functional requirements:
- Performance: large transaction searches and pagination
- Reliability: recoverable network errors and duplicate-submit prevention
- Security: masking, least-privilege UI and backend-enforced authorization
- Auditability: visible event history supplied by trusted services
- Accessibility: keyboard support and clear status communication

## Portfolio quality gate
A project is ready to publish when it has a clear business problem, runnable instructions, clean build, meaningful tests, architecture documentation, screenshots with synthetic data and no committed secrets.
