# Project README Template

Use this template for every standalone project.

## Business context
Describe the user, problem and workflow this application supports.

## Features
List implemented features and clearly mark planned features.

## Architecture
Include a component diagram or data-flow diagram. Identify frontend, backend APIs and external dependencies.

## Technology stack
List framework, language, state management, routing, testing and build tools.

## Getting started
Provide prerequisites, installation, environment configuration and run commands.

## Screenshots
Add screenshots after the UI is implemented. Do not include real customer or account data.

## Testing
Explain unit, component and end-to-end test coverage.

## Security considerations
Explain what is enforced by the backend and what is only a frontend demonstration.
