# Frontend Performance Checklist

- [ ] Capture baseline with representative routes and data.
- [ ] Inspect production build and bundle composition.
- [ ] Split large routes or rarely used modules where beneficial.
- [ ] Optimize images and fonts.
- [ ] Avoid unnecessary rerenders based on profiler evidence.
- [ ] Virtualize very large tables/lists.
- [ ] Define HTTP/CDN caching policy and invalidation.
- [ ] Measure Core Web Vitals and key user interactions.
- [ ] Test slow network and lower-powered devices.
- [ ] Confirm performance changes do not regress accessibility.
