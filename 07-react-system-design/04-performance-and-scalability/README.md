# 04 - Performance and Scalability

A hands-on reference for measuring and improving React application performance.

## Modules
- Code splitting and route-level lazy loading
- Lazy loading of heavy components and assets
- Browser, HTTP and application caching
- Rendering optimization and large-list strategies

## Core rule
Measure first. Define user-centric targets, collect a baseline, change one bottleneck at a time, and verify the result on representative devices and network conditions.
