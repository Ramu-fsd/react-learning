# 06 - Testing and Quality

Testing strategy for React applications, from pure functions to browser-level business journeys.

## Modules
- Unit testing
- Integration testing
- Component testing
- End-to-end testing

## Test pyramid
Use many fast focused tests, a useful set of integration/component tests, and a smaller number of high-value end-to-end journeys. Test behavior and outcomes rather than implementation details.
