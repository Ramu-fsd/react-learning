# Design Systems

A design system provides shared foundations for consistent user experiences.

## Layers
1. Design tokens: color, spacing, typography, elevation.
2. Primitives: button, input, dialog, badge.
3. Patterns: data table, filter bar, form layout.
4. Product composition: business-specific screens.

## Governance
- Semantic versioning and release notes.
- Accessibility standards and documented keyboard behavior.
- Contribution and deprecation policy.
- Visual regression tests.
- Theming and brand tokens.
- Ownership and support model.

A component library without documentation, governance and adoption practices is not a complete design system.
