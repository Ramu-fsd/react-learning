# Frontend Observability

Observe user experience and failures without collecting unnecessary sensitive data.

## Signals
- JavaScript errors and unhandled promise rejections.
- Route load and interaction performance.
- API latency, status and correlation IDs.
- Web Vitals and long tasks.
- Release/version metadata.

## Safe telemetry
- Redact tokens, credentials, account numbers and personal data.
- Avoid recording full form contents.
- Apply access controls and retention policies to telemetry.
- Use sampling and alert thresholds to control noise.
- Correlate with backend traces using safe request identifiers.
