# Micro-Frontend Decision Record Template

- **Business problem:** What delivery or ownership constraint are we solving?
- **Team boundaries:** Which teams own which domain UI?
- **Deployment autonomy:** Must teams release independently?
- **Integration:** Build-time, runtime federation, web components or route composition?
- **Shared dependencies:** How are React and design-system versions managed?
- **Authentication:** How is session context shared safely?
- **Resilience:** What does the shell display when a remote fails?
- **Observability:** How are errors and performance correlated?
- **Testing:** What contract and cross-application tests are required?
- **Decision:** Modular monolith or micro-frontends, with rationale and review date.
