# React Frontend Architecture - Interview Questions

1. When would you choose feature-based architecture over type-based folders?
2. What belongs in `shared`, and what should remain inside a feature?
3. How do you prevent circular dependencies between features?
4. How do you decide whether a component should be reusable?
5. Where should API calls and data transformation live?
6. How would you organize a digital banking portal with accounts, payments, customers and service requests?
7. How do you separate local UI state from server state?
8. What are the trade-offs of micro-frontends?
9. How would you improve the initial loading experience of a large React application?
10. Which frontend NFRs would you define for a high-volume payment operations portal?

## Answering framework
For each question, explain:
- Context and constraints.
- Options considered.
- Chosen boundary or pattern.
- Trade-offs and operational impact.
- How you would validate the decision.
