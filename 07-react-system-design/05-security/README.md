# 05 - React Frontend Security

Security guidance for enterprise React applications. The frontend is an untrusted client: backend services must enforce authentication, authorization, validation and business controls.

## Modules
- JWT and token management
- XSS and CSRF
- Secure API communication
- Frontend security best practices

This package is a design and learning reference, not a security certification or a substitute for threat modeling and penetration testing.
