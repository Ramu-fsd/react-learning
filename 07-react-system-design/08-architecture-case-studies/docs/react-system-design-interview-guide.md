# React System Design Interview Guide

## Recommended answer structure
1. Clarify users, workflows, scale and constraints.
2. Identify functional and non-functional requirements.
3. Draw the browser, CDN/WAF, frontend shell, BFF/API gateway and backend services.
4. Define feature boundaries and shared capabilities.
5. Explain state management and API integration.
6. Cover authentication, authorization, data protection and threat model.
7. Address performance, availability, accessibility and observability.
8. Discuss deployment, testing, trade-offs and evolution.

## Common discussion areas
- Feature-based modular monolith vs micro-frontends.
- Client state vs server state.
- Route-level code splitting and caching.
- OAuth/OIDC, PKCE, BFF and CSRF.
- Large table rendering and real-time updates.
- Error boundaries, retry policy and idempotent commands.
- Multi-tenant cache isolation.
- Frontend NFRs and observability.
