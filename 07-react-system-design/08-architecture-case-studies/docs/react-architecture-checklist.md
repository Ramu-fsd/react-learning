# React Architecture Checklist

## Product and domain
- [ ] User roles and workflows are documented.
- [ ] Domain boundaries and API ownership are clear.
- [ ] Functional and non-functional requirements are measurable.

## Frontend structure
- [ ] App shell, features and shared modules have clear responsibilities.
- [ ] Cross-feature dependencies are controlled.
- [ ] Shared components have accessibility and versioning practices.

## Data and integration
- [ ] Client and server state are separated.
- [ ] API errors and loading states are standardized.
- [ ] Caching and invalidation rules are explicit.
- [ ] Real-time event lifecycle and reconnect strategy are documented.

## Security
- [ ] Authentication uses a standards-based flow.
- [ ] Backend enforces authorization and tenant isolation.
- [ ] Sensitive browser storage and telemetry are reviewed.
- [ ] XSS and CSRF controls are defined.

## Quality and operations
- [ ] Unit, component, integration and E2E coverage is appropriate.
- [ ] Performance is measured against representative scenarios.
- [ ] Error monitoring and correlation are implemented.
- [ ] Deployment, rollback and compatibility strategy is documented.
