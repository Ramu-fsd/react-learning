# React Interview Preparation

## Core topics
- Components, props, state and rendering
- Hooks and effect lifecycle
- Controlled and uncontrolled forms
- Context API and Redux Toolkit
- TypeScript with React
- API integration and error handling

## Advanced topics
- Reconciliation and keys
- Memoization and render optimization
- Lazy loading and code splitting
- Error boundaries
- Server state and cache invalidation
- Testing with component and E2E tools

## Architecture topics
- Feature-based versus type-based folder structures
- Modular monolith versus micro-frontends
- Authentication, token handling, XSS and CSRF
- Frontend NFRs and observability
- Multi-tenant UI design
- Real-time communication and high-volume tables

## System design answer structure
1. Clarify requirements and users.
2. Identify functional and non-functional requirements.
3. Draw the high-level architecture.
4. Define feature and API boundaries.
5. Explain state ownership and data flow.
6. Cover security, resilience and performance.
7. Explain testing, deployment and observability.
8. Discuss trade-offs and future evolution.
